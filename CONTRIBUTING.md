# Contributing

This dataset is meant to be accurate and reusable. Corrections and additions are welcome.

## Found an error in a cell?

Vendor documentation changes, and we may have misread something. If a `value` is wrong or out of date:

1. [Open an issue](https://github.com/koaichapp/privacy-comparison-data/issues) describing the cell (attribute + vendor) and what it should say.
2. **Include a public source** — a vendor doc, help-center page, security whitepaper, or RFC. Claims without a citable source can't be merged, because every cell here traces back to the [methodology page](https://koaich.com/methodology).
3. Or open a PR editing the canonical data and the source list.

## Adding a vendor or attribute

Open an issue first so we can agree the attribute is well-defined and applies across vendors (an attribute that's "n/a" for most rows usually isn't worth a column).

## Scope

This is a **privacy-architecture** comparison — who can read your content, where the keys live, what metadata leaks, how recovery works. Feature/price/UX comparisons are out of scope by design.
